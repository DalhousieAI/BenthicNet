benthicnet-subsample#

Subsample a dataframe, based on distance between samples.

usage: benthicnet-subsample [-h] [--version] [--distance DISTANCE]
                            [--forbid-nonspatial]
                            [--min-population MIN_POPULATION]
                            [--target-population TARGET_POPULATION]
                            [--max-factor MAX_FACTOR | --factors FACTORS [FACTORS ...]]
                            [--exhaustive [EXHAUSTIVE]] [--global]
                            [--site-distance INTER_SITE_DISTANCE]
                            [--subsite-distance SUBSITE_DISTANCE]
                            [--subsite-population-bonus SUBSITE_POPULATION_BONUS]
                            [--subsite-min-population-bonus SUBSITE_MIN_POPULATION_BONUS]
                            [--no-progress-bar] [--verbose] [--quiet]
                            input_csv output_csv

Positional Arguments#

input_csv

Path to input CSV file, in the BenthicNet format.

output_csv

Path to output CSV file.

Named Arguments#

--version, -V

Show program’s version number and exit.

--distance

Target distance between consecutive entries in the dataframe. Default is 2.5.

--forbid-nonspatial

Disallow handling duplicated coordinates with non-spatial downsampling. If this is set, all sites will be spatially downsampled, even if they have fewer samples per coordinate than unique coordinates.

--min-population

Minimum number of samples in a single site for that site to be subsampled. Default is 50.

--target-population

Desired number of samples per site. The specified distance will by multiplied by a factor 1, 2, 3, …, MAX_FACTOR until the population falls below TARGET_POPULATION; the largest factor before falling below the TARGET_POPULATION will be used. Set to 0 or -1 to disable. Default is 1000.

--max-factor

Maximum distance factor to use when performing additional subsampling for over populated sites. The maximum distance at which to subsample is DISTANCE * MAX_FACTOR. Default is [2, 3, 4].

--factors

Set of distance factors consider when performing additional subsampling for over populated sites. Default is None.

--exhaustive

Perform an exhaustive search of the previous samples to ensure none are within DISTANCE/2 before including the next sample.

--global

Ensure no samples are within DISTANCE/2 of each other, even across multiple sites.

--site-distance, --inter-site-distance

Distance in meters between consecutive samples to detect a site. Each site grants an increase in the target population equal to TARGET_POPULATION. Default is 1000.0.

--subsite-distance

Distance in meters between consecutive samples to detect a subsite. Each subsite grants an increase in the target population equal to SUBSITE_POPULATION_BONUS. Default is 500.0.

--subsite-population-bonus

Amount of increase in target population for every additional subsite within the site. Subsites are detected when there is a gap of at least SUBSITE_DISTANCE between samples. Default is half of TARGET_POPULATION. Set to 0 or -1 to disable.

--subsite-min-population-bonus

Amount of increase in minimum population threshold for every additional subsite within the site. Default is half of MIN_POPULATION. Set to 0 or -1 to disable.

--no-progress-bar

Disable tqdm progress bar.

--verbose, -v

Increase the level of verbosity of the program. This can be specified multiple times, each will increase the amount of detail printed to the terminal. The default verbosity level is 1.

--quiet, -q

Decrease the level of verbosity of the program. This can be specified multiple times, each will reduce the amount of detail printed to the terminal.
